# Shell & Command Line Conventions

- Always use Linux-based commands, bash syntax, and POSIX conventions (such as `./gradlew`, forward slashes `/`, and bash-compatible commands).
- The user's default terminal and build environment is Git Bash / Linux-based shell.
- Do NOT use Windows batch command conventions like `.\gradlew.bat` or backslashes `\` in scripts, tasks, or execution commands.
