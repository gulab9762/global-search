# Minecraft Modding MCP Integration

When developing, refactoring, or verifying code for Fabric and NeoForge:
- Always utilize the `mcmodding-mcp` tools when looking up Fabric or NeoForge documentation, class references, mixin patterns, and API signatures rather than guessing or relying on outdated training data.
- Verify Minecraft version-specific mechanics (such as Minecraft 26.3 event lifecycles, registries, and screen rendering) against the latest modding index provided by `mcmodding`.
