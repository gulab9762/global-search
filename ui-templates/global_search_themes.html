🛠️ How to Implement These Themes in Minecraft 26.3 GuiGraphics

✨ Frosted Glass & Translucency

Use layered translucent fills with subtle top-highlight borders to achieve glass without shader overhead.

graphics.fill(x, y, x + w, y + h, 0xCC101522);
graphics.fill(x, y, x + w, y + 1, 0x33FFFFFF); // 1px specular

🏷️ Category Pill Badges

Render rounded or beveled category chips next to result titles with dedicated hex accent colors for instant scanning.

SearchResultType.getValueColor() / getBadgeColor()

⌨️ Interactive Listening Glow

Pulse the keybind editing state with a distinct amber or red border so players immediately know Minecraft is capturing their input.

Math.sin(System.currentTimeMillis() * 0.005f)

🎨 In-Game Theme Config Option

A dropdown setting in `GlobalSearchConfig` allowing players to switch between Obsidian, Netherite, Raycast, and Ender themes.

enum SearchGuiTheme { OBSIDIAN, NETHERITE, RAYCAST, ENDER }
